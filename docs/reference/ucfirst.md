# Capitalize the first letter

Capitalizes the first character is a string. Not particularly robust.
Copied over from Perl code.

## Usage

``` r
ucfirst(str)
```

## Arguments

- str:

  a string.

## Value

The same string with the first letter capitalized.

## Examples

``` r
ucfirst("foo bar")
#> [1] "Foo bar"
```
